# A Unified Inertial Encoder for Human and Humanoid Motion

Project page for the paper, built with Next.js (static export) and Tailwind CSS v4. The layout and
components (hero with masked background video, abstract, highlight slider, figure blocks,
citation) are ported from the [Co-Me](https://co-me-tokens.github.io/) project page.

## Layout

- `app/page.tsx` — the single landing page (named authors, abstract with teaser, video slider,
  method and datasets, real-G1 demos and runtime, results and ablations, interactive plots,
  limitations, citation).
- `app/globals.css` — Tailwind v4 theme tokens (`primary` palette, `dark`, `ours` table shade),
  typography, `.layout`, `scrollbar-dark`, `animated-underline`, `results-table`.
- `components/` — `Figure`, `KaTeX`, `Compare` (image slider), `VideoCard` (poster → player),
  `ResultsTables`, `links/*`.
- `constant/config.ts` — title, description, authors, site URL, GitHub link.
- `public/video/` — re-encoded H.264 clips: hero background (`hero.mp4`) and the three
  narrated segments (motivation, method, results); `public/images/posters/` holds their poster frames.
- `public/images/` — paper figures (teaser, overview, qualitative trajectories, language strip,
  t-SNE, scaling) and the real-G1 staircase recordings/estimates.

The hero's Paper button links to [the paper on arXiv](https://arxiv.org/abs/2611.10137).

Asset paths in raw `<img>`/`<video>`/`fetch` calls go through `asset()` in `lib/utils.ts`, which
prefixes the `basePath`. The site deploys as the organisation's root Pages site
(`https://unified-inertial-encoder.github.io/`), so `basePath` is empty; set `NEXT_BASE_PATH=/<repo>`
at build time only if it is ever served from a project sub-path.

## Local development

```sh
npm ci
npm run dev
```

Open http://localhost:3000. Run `npm run lint`, `npm run typecheck` and `npm run build` to check the
project; `npm run build` reproduces the deployed build (served from the domain root).

## Paper source

Content and numerical tables match the sibling `latex/` repository's November 2, 2026 Overleaf
version (`6f15545`, merged into `main` as `bc448d6`). The site retains the existing video demos
and interactive data; the scaling fit matches `latex/figures/scaling_3d_sources.json`, and the
t-SNE opens on the paper's `[CLS]` view.

Web figures are rendered from the paper PDFs at 2200 pixels wide:

- `Figure1.pdf` → `public/images/teaser.png`
- `Figure2.pdf` → `public/images/overview.png`
- `Figure5.pdf` → `public/images/real-g1-runtime.png`
- `qual_lang_g1_col.pdf`, `cls_tsne.pdf`, `scaling_3d.pdf` → matching PNG filenames

## GitHub Pages

The workflow in `.github/workflows/deploy.yml` builds and deploys the static site on pushes to `main`
or when run manually. In the repository's **Settings → Pages**, set **Build and deployment → Source**
to **GitHub Actions**. The site is built for `https://unified-inertial-encoder.github.io/unified-inertial-encoder/`.

## Interactive t-SNE

`public/tsne/` is generated by `src/scripts/export_tsne_web` in the FoundationIMU repo:
`index.json` (points, regions, per-point layout), `w/<i>.bin` (one small int16 motion file per
point, fetched on hover), and `g1.glb` + `g1_kinematics.json` (decimated Unitree G1 meshes and
joint tree). `components/tsne/TsneExplorer.tsx` draws the scatter; `MotionPreview.tsx` renders the
hovered window with three.js (humans as a capsule mannequin from the 17 XSens sites, the G1 from
its URDF).
